# CoBRA: Automated Rubric Discovery using Comparative features and Batch Aggregation

## To run the code it requires the following:
- Dataset: store the dataset into a dataset folder, create one if the folder is not available.
- Output: Outputs are stored in output folder, so please create one if it is not available.
- To run it from terminal:
- - <code>python cobra.py --nsamples [number of samples to build comparative features from] --length [llm output length]</code>
--You can can set <code>temp</code>, <code>seed</code>
- To run the baselines, follow similar approach without the sample size.
